# Homepage v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the "Clipupp Homepage v2" mockup as the live homepage, driven by real backend data, with the header, footer and mobile nav restyled to match.

**Architecture:** The backend resolves the whole homepage in one cached payload (`GET /api/v1/homepage`) through a new `HomepageResolver` class that replaces the switch in the controller. The frontend page maps seven section codes to seven server components; the only client islands are search autosuggest, the proof-line count-up, the show-code button, the category tabs and the scroll-reveal hook. One coupon card family serves the hero fan, the rail and the tabbed rows.

**Tech Stack:** Spring Boot 4 / Java 21 / Flyway / JPA / Caffeine / Mockito + JUnit 5; Next.js 15 App Router / React 19 / Tailwind / next-intl / Playwright (already in `node_modules`) / Vitest (added in Task 7 for pure helpers).

**Spec:** `docs/superpowers/specs/2026-10-12-homepage-v2-design.md`
**Mockup:** https://claude.ai/artifact/4Le1r6ohy7XAd2RYorjSqh

## Global Constraints

- Branch: `New-design-v1`. Commit after every task. Never add an agent name as co-author.
- Never use an em dash in any file or commit; use a plain dash.
- User-facing copy must say "deals", "coupons", "save". The word "cashback" never appears in rendered copy.
- Migrations are append-only: new file `V034__homepage_v2.sql`, never edit a committed one. `out-of-order: false`.
- Writes to store, coupon, category, campaign and site settings must evict `homepage.layout`. Store, coupon, category writes also evict `homepage.top` (existing rule).
- Backend tests: `cd backend/clipupp && ./gradlew test`. Dev server: `SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5435/clipupp_db ./gradlew bootRun` (the local Docker Postgres `clipupp-postgres` listens on 5435).
- Frontend checks: `cd frontend/clipupp && npm run typecheck && npm run lint && npm run test` (test added in Task 7). `npm run build` does not fail on type errors, so always run typecheck.
- Server components by default. `"use client"` only at leaves. No `useEffect` data fetching for initial render.
- Every `next/image` has explicit `width`/`height`. No layout shift. H1 stays the LCP element.
- Tokens: brand `#8529CD`, hover `#7119B8`, tints `#FAF6FD / #F5EEFB / #E7D4F5`, page `#FAFAFA`, border `#DDDDDD`, ink `#252525`, secondary text `#575757`, success `#33823F`, danger `#B90037`. Headings Zilla Slab 600, body Inter. Radii 6 / 12 / pill. No gradients.
- Motion: transform and opacity only, under 300ms except hero entrance 500ms and count-up 900ms. Everything decorative is off under `prefers-reduced-motion: reduce`.
- Markdown written by this plan (docs) puts each sentence on its own line.

```sql
-- V034: Homepage v2 (spec: docs/superpowers/specs/2026-10-12-homepage-v2-design.md)

-- 1. Admin-set verification timestamp. Drives "Verified 2h ago" on cards.
alter table coupon add column if not exists verified_at timestamptz;
update coupon set verified_at = coalesce(updated_at, created_at) where verified = true and verified_at is null;
create index if not exists idx_coupon_verified_at on coupon (verified_at desc) where verified = true and deleted_at is null;
```

Add the getter and the single mutation path, next to `setVerified`:

```java
    public OffsetDateTime getVerifiedAt() { return verifiedAt; }

    /**
     * The only way verification state changes. Verifying always refreshes the
     * timestamp (an admin re-checking a code is a fresh verification);
     * unverifying clears it so the UI never shows a stale "Verified 3d ago".
     */
    public void applyVerified(boolean verified, OffsetDateTime now) {
        this.verified = verified;
        this.verifiedAt = verified ? now : null;
    }
```

```java
    private List<CouponWithStore> attachStores(List<Coupon> coupons) {
        if (coupons.isEmpty()) return List.of();
```

```java
package com.clipupp.home.application;

import com.clipupp.campaigns.api.dto.CampaignDtos;
import com.clipupp.campaigns.application.CampaignService;
import com.clipupp.categories.application.CategoryService;
import com.clipupp.categories.domain.Category;
import com.clipupp.coupons.api.dto.CouponSummary;
import com.clipupp.coupons.application.CouponService;
import com.clipupp.coupons.application.CouponService.CouponWithStore;
import com.clipupp.home.api.dto.PublicHomepageDtos.CategoryItem;
import com.clipupp.home.api.dto.PublicHomepageDtos.CategoryTab;
import com.clipupp.home.api.dto.PublicHomepageDtos.HomepageLayout;
import com.clipupp.home.api.dto.PublicHomepageDtos.HomepageSectionPayload;
import com.clipupp.home.api.dto.PublicHomepageDtos.Stats;
import com.clipupp.home.domain.HomepageSection;
import com.clipupp.stores.api.dto.StoreSummary;
import com.clipupp.stores.application.StoreService;
import com.clipupp.stores.domain.Store;
import java.time.OffsetDateTime;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import org.springframework.stereotype.Component;

/**
 * Turns enabled homepage_section rows into the public payload. One place
 * knows which section code needs which data, so adding a section is one
 * case here plus one renderer in the frontend SECTION_RENDERERS map.
 *
 * Section codes (spec: 2026-10-12-homepage-v2-design.md):
 *   hero_search       categories (chips) + coupons (3 fanned cards)
 *   trending_coupons  coupons (verified, by popularity)
 *   featured_stores   stores with activeCouponCount
 *   top_deals         categoryTabs (pinned categories or first 7 roots, N coupons each)
 *   bank_offers       campaigns (active, newest first)
 *   verify_band       copy only
 *   newsletter        copy only
 */
@Component
public class HomepageResolver {

    static final int HERO_CHIPS = 8;
    static final int HERO_FAN = 3;
    static final int DEFAULT_TRENDING = 7;
    static final int DEFAULT_STORES = 12;
    static final int DEFAULT_TABS = 7;
    static final int DEFAULT_PER_TAB = 4;
    static final int DEFAULT_CAMPAIGNS = 2;

    private final HomepageService homepageService;
    private final StoreService storeService;
    private final CouponService couponService;
    private final CategoryService categoryService;
    private final CampaignService campaignService;

    public HomepageResolver(HomepageService homepageService,
                            StoreService storeService,
                            CouponService couponService,
                            CategoryService categoryService,
                            CampaignService campaignService) {
        this.homepageService = homepageService;
        this.storeService = storeService;
        this.couponService = couponService;
        this.categoryService = categoryService;
        this.campaignService = campaignService;
    }

    public HomepageLayout resolve(List<HomepageSection> sections) {
        List<HomepageSectionPayload> resolved = new ArrayList<>(sections.size());
        for (HomepageSection s : sections) resolved.add(resolveSection(s));
        return new HomepageLayout(resolved, stats());
    }

    private Stats stats() {
        OffsetDateTime weekAgo = OffsetDateTime.now().minusDays(7);
        return new Stats(
                couponService.countVerifiedSince(weekAgo),
                couponService.countActive(),
                storeService.countActive());
    }

    private HomepageSectionPayload resolveSection(HomepageSection s) {
        Integer limit = s.getItemLimit();
        String code = s.getCode();
        String title = s.getTitle();
        String subtitle = s.getSubtitle();
        return switch (code) {
            case "hero_search" -> new HomepageSectionPayload(code, title, subtitle, limit,
                    null, toSummaries(couponService.trendingVerifiedWithStores(HERO_FAN)),
                    categoryItems(HERO_CHIPS), null, null);
            case "trending_coupons" -> new HomepageSectionPayload(code, title, subtitle, limit,
                    null, toSummaries(couponService.trendingVerifiedWithStores(or(limit, DEFAULT_TRENDING))),
                    null, null, null);
            case "featured_stores" -> new HomepageSectionPayload(code, title, subtitle, limit,
                    storesWithCounts(or(limit, DEFAULT_STORES)), null, null, null, null);
            case "top_deals" -> new HomepageSectionPayload(code, title, subtitle, limit,
                    null, null, null, categoryTabs(or(limit, DEFAULT_PER_TAB)), null);
            case "bank_offers" -> new HomepageSectionPayload(code, title, subtitle, limit,
                    null, null, null, null,
                    campaignService.findActive(or(limit, DEFAULT_CAMPAIGNS)).stream()
                            .map(CampaignDtos.Detail::from).toList());
            default -> HomepageSectionPayload.bare(code, title, subtitle, limit);
        };
    }

    private List<StoreSummary> storesWithCounts(int take) {
        List<Store> stores = homepageService.featuredStores();
        if (stores.isEmpty()) stores = storeService.listActive(null, null, take).data();
        List<Store> picked = stores.stream().limit(take).toList();
        Map<UUID, Integer> counts = couponService.activeCountsByStore(picked.stream().map(Store::getId).toList());
        return picked.stream()
                .map(st -> StoreSummary.from(st).withActiveCouponCount(counts.getOrDefault(st.getId(), 0)))
                .toList();
    }

    private List<CategoryTab> categoryTabs(int perTab) {
        List<CategoryTab> tabs = new ArrayList<>();
        for (Category c : pickCategories(DEFAULT_TABS)) {
            tabs.add(new CategoryTab(c.getSlug(), c.getTitle(),
                    toSummaries(couponService.topInCategoryWithStores(c.getSlug(), perTab))));
        }
        return tabs;
    }

    private List<CategoryItem> categoryItems(int take) {
        return pickCategories(take).stream()
                .map(c -> new CategoryItem(c.getSlug(), c.getTitle(), c.getIcon()))
                .toList();
    }

    /** Admin-pinned categories win; otherwise the first N active roots by position. */
    private List<Category> pickCategories(int take) {
        List<Category> pinned = categoryService.findFeatured();
        List<Category> source = pinned.isEmpty() ? categoryService.activeRoots() : pinned;
        return source.stream().limit(take).toList();
    }

    private static List<CouponSummary> toSummaries(List<CouponWithStore> pairs) {
        return pairs.stream().map(p -> CouponSummary.from(p.coupon(), p.store())).toList();
    }

    private static int or(Integer limit, int fallback) {
        return limit == null ? fallback : limit;
    }
}
```

```ts
"use client";

import { useEffect } from "react";

/**
 * Adds `.in` to every `.clipupp-reveal` under `root` as it enters the
 * viewport. One observer per page; stagger is capped at 6 through the
 * `--i` custom property each element sets itself. Under reduced motion,
 * or without IntersectionObserver, everything is shown immediately.
 * A 2.5s safety timer reveals anything still hidden (fast scroll, tabs
 * rendered off-screen, etc.) so content can never be lost.
 */
export function useReveal(root: React.RefObject<HTMLElement | null>) {
  useEffect(() => {
    const el = root.current;
    if (!el) return;
    const items = Array.from(el.querySelectorAll<HTMLElement>(".clipupp-reveal"));
    if (items.length === 0) return;

    const reduce = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
    const showAll = () => items.forEach((i) => i.classList.add("in"));
    if (reduce || !("IntersectionObserver" in window)) {
      showAll();
      return;
    }

    const io = new IntersectionObserver(
      (entries) => {
        for (const e of entries) {
          if (!e.isIntersecting) continue;
          e.target.classList.add("in");
          io.unobserve(e.target);
        }
      },
      { rootMargin: "0px 0px -8% 0px" }
    );
    items.forEach((i) => io.observe(i));
    const safety = window.setTimeout(showAll, 2500);
    return () => {
      io.disconnect();
      window.clearTimeout(safety);
    };
  }, [root]);
}
```

`lib/format/timeAgo.ts`:

```ts
/**
 * Compact relative time for trust lines ("Verified 2h ago"). Returns null for
 * missing or unparseable input so callers can omit the line entirely instead
 * of rendering "NaN". Future timestamps (clock skew) read as "just now".
 */
export function timeAgo(iso: string | null | undefined, now: Date = new Date()): string | null {
  if (!iso) return null;
  const t = Date.parse(iso);
  if (Number.isNaN(t)) return null;
  const diffSec = Math.max(0, Math.floor((now.getTime() - t) / 1000));
  if (diffSec < 60) return "just now";
  const min = Math.floor(diffSec / 60);
  if (min < 60) return `${min}m ago`;
  const hr = Math.floor(min / 60);
  if (hr < 24) return `${hr}h ago`;
  const day = Math.floor(hr / 24);
  return `${day}d ago`;
}
```

```tsx
"use client";

import { useEffect, useState } from "react";
import { formatCount } from "@/lib/format/number";

/**
 * Count-up for the hero proof line: 900ms easeOutCubic from 0 to `to`.
 * Renders the final number on the server (and under reduced motion) so the
 * HTML is correct before hydration; the animation only replaces it.
 */
export function ProofCount({ to }: { to: number }) {
  const [value, setValue] = useState(to);

  useEffect(() => {
    if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) return;
    let raf = 0;
    let start: number | null = null;
    const step = (t: number) => {
      if (start === null) start = t;
      const p = Math.min(1, (t - start) / 900);
      const eased = 1 - Math.pow(1 - p, 3);
      setValue(Math.round(to * eased));
      if (p < 1) raf = requestAnimationFrame(step);
    };
    raf = requestAnimationFrame(step);
    return () => cancelAnimationFrame(raf);
  }, [to]);
```

```tsx
"use client";

import { useEffect, useId, useRef, useState } from "react";
import Image from "next/image";
import { Search } from "lucide-react";
import { Link, useRouter } from "@/lib/i18n/navigation";
import { searchApi } from "@/lib/api/search";
import type { SearchHit } from "@/lib/api/types";

/**
 * Hero search with 3-row autosuggest. The form GETs /search?q= so it works
 * without JS; the island only adds suggestions (150ms debounce, max 3) and
 * the empty state. Keyboard: Escape closes, Enter submits.
 */
export function HeroSearch({
  placeholder,
  label,
  cta,
  noResults,
}: {
  placeholder: string;
  label: string;
  cta: string;
  noResults: string;
}) {
  const router = useRouter();
  const id = useId();
  const [q, setQ] = useState("");
  const [hits, setHits] = useState<SearchHit[]>([]);
  const [open, setOpen] = useState(false);
  const [searched, setSearched] = useState(false);
  const wrap = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const term = q.trim();
    if (term.length < 2) {
      setHits([]);
      setOpen(false);
      setSearched(false);
      return;
    }
    const t = window.setTimeout(async () => {
      try {
        const res = await searchApi.suggest(term);
        setHits(res.slice(0, 3));
      } catch {
        setHits([]);
      } finally {
        setSearched(true);
        setOpen(true);
      }
    }, 150);
    return () => window.clearTimeout(t);
  }, [q]);

  useEffect(() => {
    const onDoc = (e: MouseEvent) => {
      if (!wrap.current?.contains(e.target as Node)) setOpen(false);
    };
    document.addEventListener("mousedown", onDoc);
    return () => document.removeEventListener("mousedown", onDoc);
  }, []);

  function submit(e: React.FormEvent) {
    e.preventDefault();
    const term = q.trim();
    if (!term) return;
    setOpen(false);
    router.push(`/search?q=${encodeURIComponent(term)}`);
  }

  function pathFor(h: SearchHit) {
    if (h.kind === "STORE") return `/stores/${h.slug}`;
    if (h.kind === "CATEGORY") return `/categories/${h.slug}`;
    return `/coupons/${h.slug}`;
  }

  return (
    <div ref={wrap} className="relative max-w-[560px]">
      <form action="/search" method="get" role="search" onSubmit={submit}
        className="flex h-14 items-center gap-2.5 rounded-full border border-clipupp-neutral-200 bg-white pl-5 pr-1.5 transition-shadow focus-within:border-clipupp-primary focus-within:shadow-[0_0_0_3px_#E7D4F5]">
        <Search className="h-5 w-5 shrink-0 text-clipupp-neutral-500" aria-hidden />
        <label htmlFor={id} className="sr-only">{label}</label>
        <input
          id={id}
          name="q"
          type="search"
          autoComplete="off"
          placeholder={placeholder}
          value={q}
          onChange={(e) => setQ(e.target.value)}
          onFocus={() => searched && setOpen(true)}
          onKeyDown={(e) => e.key === "Escape" && setOpen(false)}
          aria-expanded={open}
          aria-controls={`${id}-list`}
          className="min-w-0 flex-1 bg-transparent text-[17px] text-clipupp-neutral-900 outline-none placeholder:text-clipupp-neutral-500"
        />
        <button type="submit" className="inline-flex h-11 items-center rounded-full bg-clipupp-primary px-5 text-[15px] font-medium text-white transition-colors hover:bg-clipupp-primary-strong">
          {cta}
        </button>
      </form>
      {open && (
        <div id={`${id}-list`} role="listbox" className="absolute inset-x-0 top-[64px] z-dropdown rounded-xl border border-clipupp-neutral-200 bg-white p-1.5 shadow-[0_12px_32px_rgba(10,22,70,0.10)]">
          {hits.length === 0 ? (
            <p className="px-3 py-2.5 text-[14px] text-clipupp-neutral-700">{noResults.replace("{q}", q.trim())}</p>
          ) : (
            hits.map((h) => (
              <Link key={`${h.kind}-${h.id}`} href={pathFor(h)} role="option" onClick={() => setOpen(false)}
                className="flex items-center gap-3 rounded-lg px-3 py-2.5 text-[15px] hover:bg-clipupp-tint-50">
                {h.imageUrl ? (
                  <Image src={h.imageUrl} alt="" width={28} height={28} className="h-7 w-7 rounded-md object-contain" />
                ) : (
                  <span className="grid h-7 w-7 place-items-center rounded-md bg-clipupp-tint-100 text-[11px] font-semibold text-clipupp-primary">
                    {h.title.slice(0, 2).toUpperCase()}
                  </span>
                )}
                <span className="line-clamp-1 flex-1">{h.title}</span>
                <small className="text-clipupp-neutral-500">{h.kind === "STORE" ? "Store" : h.kind === "CATEGORY" ? "Category" : "Coupon"}</small>
              </Link>
            ))
          )}
        </div>
      )}
    </div>
  );
}
```

```tsx
import { useState } from "react";

import { toast } from "sonner";
import { newsletterApi } from "@/lib/api/newsletter";
import { isApiError } from "@/lib/api/errors";
import type { HomepageSectionPayload } from "@/lib/api/homepage";

type Copy = { headline?: string; subheadline?: string; cta?: string };

/**
 * Block 7: white newsletter band. Headline from the section row, fallback to
 * the newsletter.* site settings. Form posts through newsletterApi; on
 * success the button reads "Subscribed ✓" and stays disabled.
 */
export function NewsletterBar({ section, copy }: { section?: HomepageSectionPayload | null; copy?: Copy }) {
  const t = useTranslations("home.newsletter");
  const locale = useLocale();
  const [email, setEmail] = useState("");
  const [state, setState] = useState<"idle" | "busy" | "done">("idle");

  const headline = section?.title?.trim() || copy?.headline || "Best deals, once a week.";
  const sub = section?.subtitle?.trim() || copy?.subheadline || "";

    e.preventDefault();
    if (state !== "idle" || !email.trim()) return;
    setState("busy");
    try {
      await newsletterApi.subscribe(email.trim(), locale);
      setState("done");
      toast.success(t("success"));
    } catch (err) {
      setState("idle");
      toast.error(isApiError(err) ? err.message : t("error"));
    }
  }

  return (
    <section className="clipupp-container grid items-center gap-8 py-14 lg:grid-cols-2 lg:gap-12 lg:py-24" aria-labelledby="newsletter-heading">
      <div className="clipupp-reveal">

        {sub && <p className="mt-2.5 text-clipupp-neutral-700">{sub}</p>}
      </div>
      <div className="clipupp-reveal" style={{ "--i": 1 } as React.CSSProperties}>
        <form onSubmit={onSubmit} className="flex max-w-[520px] gap-2">
          <label htmlFor="newsletter-email" className="sr-only">{t("emailLabel")}</label>

            className={"inline-flex h-12 items-center rounded-full px-5 text-[15px] font-medium text-white transition-colors " + (state === "done" ? "bg-clipupp-success" : "bg-clipupp-primary hover:bg-clipupp-primary-strong disabled:opacity-70")}>
```
